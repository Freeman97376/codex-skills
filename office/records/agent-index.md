# Agent 工作入口

先读项目根 AGENTS.md 和 office/AGENTS.md；新任务或上下文恢复后按下列顺序进入，任务内基线或规则变化时重新核对。本页是导航，不授予权限。

1. 读 [当前状态](current-state.md)，核对实际根目录、分支、提交与未提交改动。
2. 读 [项目概览](overview.md) 和 [架构导航](architecture/overview.md)，仅展开任务相关模块。
3. 查 [有效决策及历史](decision-log.md)、[测试证据索引](test-ledger.md) 与 [任务历史](task-log.md)。
4. 若存在相关 handoffs 记录，确认目标、阻塞、下一步与当前授权；不要自动恢复旧外部操作。
5. 将代码事实、历史报告、计划和当前验证分开。未重跑的测试不得写成当前通过。

人类入口为 [项目阅读首页](README.md)。两个入口共用上述事实。写入需在当前任务授权范围内；历史追加/更正，现状更新，接续完成后保留最终状态。不要批量迁移历史或自动删除原始证据。

收尾按 [记录生命周期](../skills/manage-agent-governance/references/records.md) 检查实际差异：更新受影响的共用事实，在回复中说明已更新、无需更新的原因及延后项。仅导航或摘要改变时调整入口；只读任务不写记录。
