# frontend-gacha

根据一份提示词生成 **5 个小范围的可交互前端演示**，在同一个比较页中筛选，保留全部方案并单独整理选中的代码。

## 使用

    $frontend-gacha 为阅读收藏工具做五种风格的小演示，展示三条收藏，并支持收藏切换和筛选。

现有项目会沿用其需求与约束。默认使用可直接预览的 HTML/CSS/JavaScript；明确要求框架时，采用隔离的框架预览并输出可独立查看的静态演示。

所有演示代码、说明、预览和选中结果都放在**目标项目根目录**的 ./office/frontend-gacha/ 下。每次重抽建立新轮次，已有方案保留。

    office/frontend-gacha/<主题>/round-01/
      index.html                 比较页
      brief.md                   共同需求、网页参考、设计方向与物料清单
      fixture.json               共用示例数据
      manifest.json              五个方案的名称与说明
      variants/A/ ... E/          独立演示代码
      selections/<选择编号>/     选中代码与来源记录

你可以在任务中回复“选 B”。也可以在比较页中选择并复制结果，再粘贴到任务中。比较页不会自动向 Codex 发消息；技能收到选择后才整理选中代码。融合或重抽可在后续消息中提出。

此技能负责小范围风格探索。助手生成演示内容，随附 Python 工具负责创建轮次、构建比较页和复制选中代码。选中后默认单独交付；整合到应用由后续明确请求决定。

## 网页参考、字体与版式

每轮设计前，通常实际查看 **至少两个同类网站的 3–5 个相关页面**，记录链接、观察依据和借鉴方式。比如技术博客可从 [AWS Blogs](https://aws.amazon.com/blogs/) 和 [Microsoft Developer Blogs](https://devblogs.microsoft.com/) 出发，再根据需求查看列表页、文章页或其他同类网站。它们是参考入口，不是固定模板；不能只看搜索摘要就宣称分析过视觉设计。访问受限时会说明实际查看范围和暂定判断。

五套方案会分别设计标题、正文、注释和代码的字体角色，通过字体搭配、字重、字号、行宽和节奏拉开差异，并检查中文及混合文本的实际字体回退。版式会根据内容安排主次、列宽、对齐、缩进与留白，减少机械重复的等宽卡片和居中布局。允许有理由的错落和非对称，同时保持阅读顺序、局部对齐和手机端可用性；不会为了变化随意摆歪元素或堆叠字体。

## 阅读舒适度

五套方案共用可读性底线。正文优先从常规或中等字重尝试，按实际字体调整；小字号、中文笔画和次要文字要清楚，不能靠普遍变细、变淡制造层次。检查文字颜色与实际背景的搭配，包括透明度、图片背景以及本轮包含的深浅主题和交互状态。

普通信息文字的对比度以至少 4.5:1 为底线；用于识别控件及状态的必要边界或标记至少达到 3:1。装饰分隔线可以更轻。字号和边框粗细依据实际显示调整，不把所有文字加粗，也不为所有区块加重边框。具体适用范围见 [阅读舒适度检查](references/reference-research-and-materials.md#reading-comfort-across-all-five-directions)。

每轮会同时检查正常缩放下的真实观感和实际颜色对的对比度，把测量结果与未验证项写入 brief.md。数值达标后仍要检查细字、细线是否显得发虚；这些检查不代表完成了全面无障碍审计。

## 物料需求与生成权限

设计前会检查本轮需要的图标、封面、插画、截图、字体等物料，区分已有可用、缺失待提供、建议生成和已授权生成，并写入 brief.md。缺少什么、用在哪里、建议的数量与规格，会明确提示，不会悄悄省略。

**没有明确授权，不自行生成图标、插画或其他新视觉物料。** 这也包括用 SVG 或 canvas 绘制自定义图形，不能换种工具绕过确认。已有的项目图标和可用素材可以复用；普通布局、边框和文字排版照常进行。等待物料决定时，可先用文字控件或明确标识的占位继续演示；仍缺物料的方案会标为待完善。授权生成某类图标不代表同时授权生成封面或 logo，选中某套方案也不会自动授权补图。

例如可以这样发起：

    $frontend-gacha 为技术博客做五种小演示，参考 AWS 和 Microsoft 的博客，重点比较字体和版式。需要哪些物料先告诉我；先用已有图标，封面留占位。

详细执行规则见 [参考网站与物料指南](references/reference-research-and-materials.md)。
